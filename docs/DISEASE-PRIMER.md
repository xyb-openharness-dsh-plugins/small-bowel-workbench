## 一、定义

小肠腺癌是起源于小肠黏膜上皮的恶性肿瘤，最常见于十二指肠，其次为空肠与回肠。小肠包括十二指肠、空肠和回肠三段；腺癌是小肠恶性肿瘤里最常见的组织学类型之一，但小肠本身占全部消化道恶性肿瘤的比例很低，所以它属于少见肿瘤。

诊断边界很重要：

- **壶腹部癌**发生在十二指肠大乳头（Vater 壶腹）区域，常与胆管、胰管受累一起讨论，分期与手术方式与小肠腺癌不同。
- **胰胆来源**的腺癌（胰腺、远端胆管）若侵犯十二指肠，原发灶不在小肠，不能按小肠腺癌记录。
- **GIST、神经内分泌肿瘤、淋巴瘤**是小肠的其他肿瘤类型，治疗路径不同，本台不设专属页面。

小肠腺癌的危险因素在公开资料中常被提到：克罗恩病、乳糜泻、林奇综合征、家族性腺瘤性息肉病（FAP）、Peutz–Jeghers 综合征等。它们只说明「风险关联」，不等于每个患者都有遗传背景；是否做遗传咨询由医生判断。

## 三、目前治疗全景概要（只做范围说明，不做推荐）

公开资料里，小肠腺癌的治疗通常围绕以下几件事展开，具体到个人由医生决定：

1. **手术**：局限于小肠、可切除的病变以根治性切除为目标，包括受累肠段与区域淋巴结。切缘（R0/R1/R2）与淋巴结数量由病理报告记录。十二指肠部位的手术方式与空肠/回肠不同，可能涉及胰十二指肠切除。
2. **术后辅助治疗**：是否做、做什么方案，取决于病理风险因素与医生判断。公开资料常参考结直肠癌的氟尿嘧啶/奥沙利铂方案，但这属于**证据外推**，不是本台的建议。
3. **晚期/不可切除**：以系统治疗为主，方案由肿瘤内科医生按病理、分子结果、体能状态与既往治疗决定。
4. **分子检测**：MSI/dMMR、HER2、NTRK、BRAF、KRAS/NRAS 等结果可能影响后续选择；本台只保存报告原文，不判断「该用什么药」。
5. **支持治疗**：营养、疼痛、恶心呕吐、腹泻、肠梗阻风险的处理，按医生与营养师安排记录。

## 四、发展趋势

- **分子分型进入常规讨论**：MSI-H/dMMR 的免疫治疗、HER2 与 NTRK 等靶点在小肠腺癌中的检测与用药证据仍在积累；本台只记录检测结果与医生原话。
- **少见的病种向高容量中心集中**：手术量与病理判读经验会影响决策，患者常需要第二意见；工作台帮助整理材料，不替代转诊判断。
- **营养与生活质量管理前移**：广泛小肠切除后的吸收不良、维生素缺乏与体重变化，越来越被视为长期随访的一部分。
- **临床试验仍是主要证据来源**：小肠腺癌专属试验数量有限，患者常需要跨癌种试验；本台预留试验收藏与检索通道，未接通前如实标注。
